# LeadGen Finder

A lightweight lead generation web app for freelancers and agencies who need clients in industries like salons, restaurants, dentists, hotels, painting companies, travel agencies, and more.

## Features

- Filter leads by industry, city, country, business age, and business size.
- Track whether each business has:
  - Website
  - Instagram
  - Facebook
  - YouTube
  - LinkedIn
  - TikTok
  - Snapchat
  - X
- For available platforms, show:
  - Profile link
  - Follower count
  - Account creation date
  - Activity consistency

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.
